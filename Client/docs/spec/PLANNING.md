# PenStreamClient 기획서

## 1. 개요

### 1.1 프로젝트 목적

PenStreamServer와 연동하여 실시간 펜 필기 데이터와 음성을 송수신하는 크로스플랫폼 클라이언트 애플리케이션

### 1.2 클라이언트 종류

| 클라이언트 | 주요 역할 | 대상 사용자 |
|-----------|----------|------------|
| **PenStreamer** | 필기 송신 (Host/Guest) | 펜으로 필기하는 사용자 |
| **PenReceiver** | 필기 수신 (Guest) | 필기를 시청하는 사용자 |
| **PenStreamAdmin** | 세션 관리/모니터링 | 관리자 |

### 1.3 핵심 기능

- **실시간 필기 송신**: 스마트펜 또는 태블릿 입력을 점 단위로 실시간 전송
- **실시간 필기 수신**: 다른 사용자의 필기를 부드럽게 렌더링
- **음성 채팅**: 양방향 실시간 음성 통신
- **세션 관리**: 세션 생성, 참가, 나가기
- **히스토리 동기화**: 늦은 참가 시 이전 필기 데이터 수신
- **오프라인 지원**: 연결 끊김 시 로컬 버퍼링 및 재연결

## 4. 클라이언트 기능 상세

### 4.1 필기 송신 (PenStreamer)

#### 4.1.1 입력 소스

| 입력 소스 | 설명 | 지원 데이터 |
|-----------|------|-------------|
| **Neo Smartpen** | Bluetooth 연결 스마트펜 | X, Y, Pressure, Timestamp, PageId |
| **Tablet/Stylus** | 태블릿 터치/스타일러스 | X, Y, Pressure |
| **Mouse** | 마우스 입력 (개발용) | X, Y |

#### 4.1.2 필기 데이터 처리

```
┌───────────────┐    ┌───────────────┐    ┌───────────────┐
│   입력 장치    │───▶│  Stroke       │───▶│    Binary     │
│ (Pen/Tablet)  │    │  Processor    │    │   Protocol    │
└───────────────┘    └───────────────┘    └───────┬───────┘
                                                   │
                                                   ▼
                                          ┌───────────────┐
                                          │   Socket.io   │
                                          │   (서버 전송)  │
                                          └───────────────┘
```

#### 4.1.3 스트로크 생성 로직

```csharp
// 펜다운 시
OnPenDown(x, y, pressure) {
    currentStroke = new Stroke {
        Id = Guid.NewGuid(),
        PageId = currentPageId,
        Color = currentColor,
        Thickness = currentThickness,
        PenType = currentPenType,
        Timestamp = DateTimeOffset.UtcNow.ToUnixTimeMilliseconds()
    };

    // STROKE_START 전송
    SendStrokeStart(currentStroke);
}

// 펜 이동 시
OnPenMove(x, y, pressure, timestamp) {
    var point = new StrokePoint {
        StrokeId = currentStroke.Id,
        X = x,
        Y = y,
        Pressure = pressure,  // uint16 (0~65535)
        Timestamp = timestamp
    };

    currentStroke.Points.Add(point);

    // STROKE_POINT 전송 (즉시)
    SendStrokePoint(point);
}

// 펜업 시
OnPenUp() {
    // STROKE_END 전송
    SendStrokeEnd(currentStroke.Id);

    completedStrokes.Add(currentStroke);
    currentStroke = null;
}
```

### 4.2 필기 수신 및 렌더링 (PenReceiver)

#### 4.2.1 렌더링 파이프라인

```
┌───────────────┐    ┌───────────────┐    ┌───────────────┐
│   Socket.io   │───▶│   Message     │───▶│   Stroke      │
│   (수신)       │    │   Parser      │    │   Manager     │
└───────────────┘    └───────────────┘    └───────┬───────┘
                                                   │
                                                   ▼
┌───────────────┐    ┌───────────────┐    ┌───────────────┐
│    Canvas     │◀───│   Renderer    │◀───│   Stroke      │
│   (화면)       │    │               │    │   Cache       │
└───────────────┘    └───────────────┘    └───────────────┘
```

#### 4.2.2 실시간 렌더링

| 단계 | 처리 내용 |
|------|----------|
| STROKE_START 수신 | 새 스트로크 객체 생성, 사용자별 색상 매핑 |
| STROKE_POINT 수신 | 포인트 추가, **즉시 화면에 선분 그리기** |
| STROKE_END 수신 | 스트로크 완료, 안티앨리어싱 적용 |

#### 4.2.3 부드러운 렌더링 기법

```csharp
// Bezier Curve로 부드러운 선 그리기
void RenderStrokePoint(StrokePoint newPoint) {
    if (stroke.Points.Count < 2) return;

    var p0 = stroke.Points[^3];  // 3번째 이전 점
    var p1 = stroke.Points[^2];  // 2번째 이전 점
    var p2 = stroke.Points[^1];  // 이전 점
    var p3 = newPoint;           // 새 점

    // Catmull-Rom to Bezier 변환
    var bezier = CatmullRomToBezier(p0, p1, p2, p3);

    // 필압에 따른 굵기 변화
    var startWidth = CalculateWidth(p1.Pressure, stroke.Thickness);
    var endWidth = CalculateWidth(p2.Pressure, stroke.Thickness);

    // 베지어 곡선 렌더링
    canvas.DrawBezierWithVariableWidth(bezier, startWidth, endWidth, stroke.Color);
}
```

## 7. 데이터 모델 (클라이언트)

### 7.1 세션 정보

```csharp
public class Session
{
    public Guid Id { get; set; }
    public string Code { get; set; }           // 6자리 접속 코드
    public SessionStatus Status { get; set; }  // Active, Paused, Closed
    public User Host { get; set; }
    public List<Participant> Participants { get; set; }
    public DateTime CreatedAt { get; set; }
    public Guid? LinkedArchiveId { get; set; }
}

public class Participant
{
    public Guid UserId { get; set; }
    public string UserName { get; set; }
    public ParticipantRole Role { get; set; }  // HOST, GUEST
    public DateTime JoinedAt { get; set; }
    public bool IsMuted { get; set; }
    public bool IsSpeaking { get; set; }
}
```

### 7.2 스트로크 데이터

```csharp
public class Stroke
{
    public Guid Id { get; set; }
    public Guid UserId { get; set; }           // 작성자
    public uint PageId { get; set; }
    public uint Color { get; set; }            // ARGB
    public float Thickness { get; set; }       // mm 단위
    public PenType PenType { get; set; }
    public StrokeFlags Flags { get; set; }
    public long StartTimestamp { get; set; }
    public List<StrokePoint> Points { get; set; }
}

public class StrokePoint
{
    public float X { get; set; }               // mm 단위
    public float Y { get; set; }               // mm 단위
    public ushort Pressure { get; set; }       // 0~65535
    public long Timestamp { get; set; }        // Unix ms
}

public enum PenType : byte
{
    Pen = 0,
    Highlighter = 1,
    Eraser = 2,
    Brush = 3
}

[Flags]
public enum StrokeFlags : byte
{
    None = 0,
    PressureSensitive = 1,
    TiltSensitive = 2
}
```
