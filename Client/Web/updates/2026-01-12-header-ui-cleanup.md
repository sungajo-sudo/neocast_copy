# 헤더 UI 정리 - 모바일 반응형 개선

2026-01-12

## 변경 요약
좁은 화면에서 헤더 UI 요소를 정리하여 공간을 절약하고 가독성을 개선했습니다.

## 변경된 파일
- `src/App.tsx`: 헤더 영역의 반응형 표시 로직 수정

## 상세 내용

### 1. 서버 연결 아이콘 숨김 (410px 미만)
- **변경 전**: `block md:hidden` - 768px 미만의 모든 화면에서 서버 아이콘 표시
- **변경 후**: `hidden min-[410px]:block md:hidden` - 410px~767px 사이에서만 표시
- 매우 좁은 화면(410px 미만)에서는 서버 연결 상태 아이콘이 숨겨져 공간 확보

### 2. 세션 배지에서 세션 코드 제거
- **변경 전**: `Host: XR5D7Y` 또는 `Guest: XR5D7Y` 형식으로 표시
- **변경 후**: `Host` 또는 `Guest`만 표시
- 세션 코드는 드롭다운 메뉴에서 복사 기능을 통해 여전히 접근 가능
