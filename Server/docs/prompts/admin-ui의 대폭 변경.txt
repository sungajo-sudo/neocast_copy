Admin 페이지를 구현한다. Server/admin-ui 안에 있다. admin-ui를 아래와 같이 개선해라.

0) 이용자 통계
   - 등록자 수 (누적, 일간, 주간, 월간, 연간)
   - 로그인 회수 (누적, 일간, 주간, 월간, 연간)
   - 사용 지속시간(로그인->로그아웃)의 평균 (누적, 일간, 주간, 월간, 연간), 웹소켓 연결 시간으로 볼 수 있을 듯.
   - 평균 세션 시간

1) Ncode 발행과 관련된 통계도 넣어야 하고
   - 전체 Ncode 발행 총량 (페이지수), (누적, 일간, 주간, 월간, 연간)
   - 내 교재로 등록한 교재 수, (누적, 일간, 주간, 월간, 연간)
   - 교재를 등록한 고객 수 (누적, 일간, 주간, 월간, 연간)
   - 교재등록 순위 (높은 곳에서 부터, 20명씩 페이징) (누적, 일간, 주간, 월간, 연간)

2) 채팅 관련된 통계도 넣어야 하고
   - 채팅 메시지 수 (누적, 일간, 주간, 월간, 연간)
   - 채팅 첨부파일 보관 스토리지 용량 (누적, 일간, 주간, 월간, 연간)

3) 메신저 활동
   - 메신저

4) 물리적인 내용
   - Storage에 저장된 용량 (누적, 일간, 주간, 월간, 연간)
   - 등록된 PDF의 리스트와 preview


5) 세션 관련된 통계가 업데이트되고 있지 않는 문제를 해결해야 한다.



서버 API를 추가하는 과정에서 **기존의 API를 수정해서는 안된다. 반드시 이전 버전과 하위호환성을 가져야 한다**
