# neocast 1.0 기획문서

이 스킬은 neocast 1.0 서비스의 기획문서를 포함합니다.

## 사용법

화면 개발 요청 시:
1. prd/ 폴더에서 관련 PRD 검색 (화면명 또는 화면 ID로)
2. PRD의 Figma Node ID로 디자인 확인
3. "화면 요소 및 기능" 섹션 기반으로 구현
4. "상태별 대응" 섹션의 Loading/Success/Empty/Error 처리 포함
