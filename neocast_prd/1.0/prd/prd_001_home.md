## 1. 화면 개요 (Overview)

- **화면 ID**: `HOME-01`
- **화면명**: 홈 (Home)
- **화면 경로**: 미정
- **Figma Node ID**: 미정
- **대상 사용자**: 로그인된 사용자 (교사)
- **비즈니스 목적**: 로그인 후 첫 진입 화면으로, 새 세션 시작과 최근 참여한 세션 목록을 한눈에 확인하여 수업 진입 동선을 최소화한다.

### 주요 사용자 흐름 (Happy Path)

1. 로그인 완료 후 홈 화면에 진입한다.
2. 상단 인사 문구("안녕하세요, {사용자명}님!")와 함께 [새 세션 시작] 카드 및 참여한 세션 목록이 표시된다.
3. [새 세션 시작] 카드를 클릭하여 새 세션 생성 화면으로 이동하거나,
4. 참여한 세션 목록에서 항목을 클릭하여 해당 세션의 아카이브 상세 화면으로 이동한다.

## 2. 화면 구성 (Elements & Functions)

### 2.1 GNB (Global Navigation Bar)

**전체 공통:**
- NeoCAST 로고 클릭하여 홈으로 이동
  - 조건: 항상 표시
- 사용자명(우측 상단) 클릭하여 계정 드롭다운 메뉴 열기
  - 성공: 드롭다운 메뉴 노출
  - 조건: 항상 표시

### 2.2 새 세션 시작 카드

**전체 공통:**
- [새 세션 시작] 카드 클릭하여 새 세션 생성 화면으로 이동
  - 성공: 새 세션 생성 화면(`SESSION-01`)으로 이동
  - 조건: 항상 활성화
  - UI 구성: 좌측 파란 [+] 원형 버튼, "새 세션 시작" 타이틀, "지금 바로 수업을 시작하세요" 부제, 우측 › 화살표

### 2.3 참여한 세션 목록

**전체 공통:**
- 세션 목록 항목 클릭하여 아카이브 상세 화면으로 이동
  - 성공: 해당 세션의 아카이브 상세 화면(`ARCHIVE-01`)으로 이동
  - 조건: 세션 데이터가 1건 이상인 경우
  - 표시 항목: 세션명, 날짜(YYYY.MM.DD), 참가자 수(N명), 우측 › 화살표
  - 정렬: 최신 날짜 순(내림차순)

## 3. 상태별 변화

### HOME-01:기본상태

- **상태 설명**: 참여한 세션이 1건 이상 존재하는 기본 상태
- **전환 트리거**: 로그인 완료 → 홈 화면 진입

#### 세션 목록

**전체 공통:**
- 세션 항목 리스트 표시 (최신 순)
  - 표시 예: 중학교 수학 - 이차방정식 / 2026.03.10 / 12명

### HOME-01:Empty

- **상태 설명**: 참여한 세션이 한 건도 없는 경우
- **전환 트리거**: 신규 가입 후 첫 진입, 또는 모든 세션 삭제 후

#### 세션 목록

**전체 공통:**
- "아직 참여한 세션이 없습니다." 안내 문구 표시
  - 조건: 세션 데이터가 0건인 경우
