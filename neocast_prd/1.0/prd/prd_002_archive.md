## 1. 화면 개요 (Overview)

- **화면 ID**: `ARCHIVE-01`
- **화면명**: 아카이브 상세 (Archive Detail)
- **화면 경로**: 미정
- **Figma Node ID**: 미정
- **대상 사용자**: 로그인된 사용자 (교사 — 호스트 또는 게스트)
- **비즈니스 목적**: 종료된 세션의 결과를 한 화면에서 확인하는 아카이브 상세 페이지. 참가자 수·진행 시간·첨삭 횟수 등 요약 통계와 참가자별 필기 이미지를 열람하고, 워크시트를 보기·인쇄할 수 있도록 지원한다.

### 주요 사용자 흐름 (Happy Path)

1. 홈 화면(`HOME-01`) 세션 목록에서 항목을 클릭하여 진입한다.
2. 세션명, 일시, "종료" 배지, 요약 통계 카드(참가자 수 / 진행 시간 / 첨삭 횟수)가 상단에 표시된다.
3. 세션에 업로드된 PDF가 있을 경우 워크시트 파일 바가 노출되며, 파일이 여러 개인 경우 드롭다운([▼])으로 파일을 선택하고 [보기] 또는 [인쇄] 버튼을 클릭한다.
4. "참가자 필기" 섹션에서 실제 필기를 한 인원의 카드를 확인하고, 카드 클릭 시 상세 화면(`HOST-REPLAY-DETAIL`)으로 이동한다.

## 2. 화면 구성 (Elements & Functions)

### 2.1 GNB

**전체 공통:**
- NeoCAST 로고 클릭하여 홈으로 이동
  - 조건: 항상 표시
- 언어 선택 드롭다운 클릭하여 UI 언어 변경
  - 성공: 선택한 언어로 UI 변경
- 사용자명 드롭다운 클릭하여 계정 메뉴 열기
  - 조건: 항상 표시

### 2.2 헤더 — 세션 기본 정보

*표시 전용, 사용자 액션 없음.*

- 세션명
- 세션 종료 날짜 및 시간
- 세션 상태 배지 (예: 종료)

### 2.3 요약 통계 카드

*표시 전용 — 3개 카드 가로 배치.*

| 카드 | 표시 값 예시 | 비고 |
| :--- | :---------- | :--- |
| 참가자 수 | 8명 | |
| 진행 시간 | 45분 | 세션 진행 시간 표시. 포맷 규칙: `duration < 60분` → `mm분`, `duration ≥ 60분` → `Xh Ym`. 단위 텍스트(분/h/m)는 사용자 UI 언어 설정에 따라 현지화 적용 |
| 첨삭 횟수 | 12회 | 하단에 "호스트 첨삭 사용 횟수" 부연 텍스트 표시 |

### 2.4 워크시트 파일 바

**전체 공통:**
- 세션에 업로드된 PDF가 있을 경우에만 노출
  - 없으면 해당 영역 숨김
  - 표시 항목: 업로드된 PDF 파일명, 페이지 수, SOBP
- [▼] 드롭다운 클릭하여 워크시트 파일 선택
  - 조건: 업로드된 PDF가 2개 이상인 경우에만 드롭다운 활성화
- [보기] 버튼 클릭하여 워크시트 미리보기
  - 성공: 로컬 환경에서 PDF 열림
- [인쇄] 버튼 클릭하여 워크시트 인쇄
  - 성공: 로컬 환경에서 인쇄 다이얼로그 실행

### 2.5 참가자 필기 섹션

**전체 공통:**
- 섹션 타이틀에 실제 필기를 한 인원 수 표시 (예: 참가자 필기 (6명))
- 필기 카드 클릭하여 상세 화면으로 이동
  - 성공: 상세 화면(`HOST-REPLAY-DETAIL`)으로 이동
  - 표시 항목: 첫 번째 페이지 필기 이미지 썸네일, 하단 참가자 이름, 역할 배지 (호스트/게스트)
  - 정렬: 호스트 첫째, 이후 게스트 이름 '가나다' 순
  - 조건: 필기 참가자가 1명 이상인 경우 표시

## 3. 상태별 변화

### ARCHIVE-01:기본상태

- **상태 설명**: 세션 데이터와 참가자 필기가 정상 로드된 상태
- **전환 트리거**: 홈 세션 목록 항목 클릭 → 화면 진입

#### 참가자 필기 섹션

**전체 공통:**
- 참가자별 필기 카드 3열 그리드 표시

### ARCHIVE-01:Loading

- **상태 설명**: 세션 데이터 및 필기 이미지 로딩 중인 상태
- **전환 트리거**: 화면 최초 진입 시

#### 전체 영역

**전체 공통:**
- 요약 통계 카드 영역 스켈레톤 UI 표시
- 참가자 필기 카드 영역 스켈레톤 UI 표시

### ARCHIVE-01:Empty

- **상태 설명**: 필기 데이터가 없는 세션인 경우
- **전환 트리거**: 세션 진행 중 아무도 필기하지 않은 경우

#### 참가자 필기 섹션

**전체 공통:**
- "필기 데이터가 없습니다." 안내 문구 표시
  - 조건: 필기 참가자 수 = 0

- **`HOST-REPLAY-DETAIL`**: 호스트 리플레이 상세 — 참가자 필기 카드 클릭 시 이동
