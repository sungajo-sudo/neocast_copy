## 1. 화면 개요 (Overview)

- **화면 ID**: `SESSION-01`
- **화면명**: 세션 입장
- **화면 경로**: 미정
- **Figma Node ID**: 미정
- **대상 사용자**: 로그인된 사용자 (교사)
- **비즈니스 목적**: 홈에서 [새 세션 시작] 버튼을 누르면 진입하는 화면. 세션을 새로 생성(호스트)하거나, 공유받은 코드로 기존 세션에 참여(게스트)할 수 있다.

### 주요 사용자 흐름 (Happy Path)

1. 홈(`HOME-01`)에서 [새 세션 시작] 버튼을 클릭하여 진입한다.
2. 기본 상태는 [새 세션 생성]이 선택된 상태로 진입한다.
3. 좌측 메뉴에서 [새 세션 생성] 또는 [참여하기]를 선택하면 우측 폼이 전환된다.
4. **세션 생성**: 세션명 입력 후 [생성하기] 클릭 → 세션 입장
5. **세션 참여**: 세션 코드 입력 / 비밀번호(선택) 입력 후 [참여하기] 클릭 → 세션 입장

## 2. 화면 구성 (Elements & Functions)

### 2.1 좌측 패널

**전체 공통:**
- 상단 헤더 텍스트:
  - 소제목: "환영합니다!" (회색 소문자)
  - 메인 타이틀: "새로운 세션을 시작하거나," (굵은 텍스트)
  - 부제: "초대받은 세션에 참여해보세요." (회색 소문자)
- [새 세션 생성] 항목 클릭하여 세션 생성 폼으로 전환
  - 성공: 우측 폼이 `SESSION-01:CREATE` 상태로 전환
  - UI: 파란 원형 [+] 아이콘, "새 세션 생성" 타이틀, "호스트가 되어 수업이나 회의를 시작하세요." 부제
- [참여하기] 항목 클릭하여 세션 참여 폼으로 전환
  - 성공: 우측 폼이 `SESSION-01:ATTEND` 상태로 전환
  - UI: 원형 [G] 아이콘, "참여하기" 타이틀, "공유받은 세션 코드를 입력하여 참여하세요." 부제
- 현재 선택된 항목: 흰색 배경 + 파란 테두리 하이라이트 표시

### 2.2 우측 폼 — SESSION-01:CREATE

**전체 공통:**
- 폼 타이틀: "NeoCAST Session" (중앙 정렬)
- 세션명 텍스트 필드에 세션명 입력 (필수)
  - 플레이스홀더: "세션명을 입력해주세요"
  - **유효성 검증 조건**:
    1. 필수 입력 — 미입력(공백만 포함) 시 "세션명을 입력해주세요" 오류 표시
    2. 최소 길이 — 2자 미만 시 "세션명은 최소 2자 이상 입력해주세요" 오류 표시
    3. 최대 길이 — 30자 초과 입력 불가 (입력 차단), 입력창 우하단에 현재 글자 수 `N/30` 표시
  - 허용 문자: 한글, 영문, 숫자, 특수문자 모두 허용
  - 검증 시점: [생성하기] 버튼 클릭 시
  - 오류 표시 위치: 입력 필드 하단 (빨간 텍스트)
  - 오류 해제 시점: 입력값 변경 시 오류 메시지 즉시 제거
- 세션 비밀번호 — 자동 생성된 비밀번호 노출, 직접 편집 가능
  - 부연 텍스트: "자동 생성된 비밀번호입니다. 직접 수정하거나 ↺로 재생성할 수 있습니다."
  - ↺ 버튼 클릭 시 새 비밀번호 자동 생성
  - **유효성 검증 조건**:
    1. 허용 문자: 영문 대소문자(A–Z, a–z) + 숫자(0–9)만 허용, 특수문자 입력 차단 (입력 즉시 필터)
    2. 길이: 정확히 6자. 6자 미만 시 "비밀번호는 6자리로 입력해주세요" 오류 표시
    3. 최대 입력: 6자 초과 입력 불가 (입력 차단)
  - 검증 시점: [생성하기] 버튼 클릭 시
  - 빈값 허용: 비밀번호를 입력하지 않으면 비밀번호 없는 세션으로 생성
- [게스트 모드 허용] 체크박스 클릭하여 게스트 참여 허용 여부 설정
  - 기본값: 체크(허용) 상태
- [생성하기] 버튼 클릭하여 세션 생성 및 입장
  - 성공: 세션 생성 완료 후 세션 진행 화면으로 이동
  - 조건: 항상 활성화 (클릭 시 유효성 검증 실행)
  - **서버 오류 처리**:

    | 오류 상황 | HTTP | 표시 방식 | 메시지 |
    |----------|------|----------|--------|
    | 인증 만료 | 401 | 오류 배너 + 자동 로그인 이동 | "로그인이 만료되었습니다. 다시 로그인해주세요." |
    | 서버 오류 | 500 | 폼 하단 오류 배너 | "서버 오류가 발생했습니다. 잠시 후 다시 시도해주세요." |
    | 네트워크 오류 | - | 폼 하단 오류 배너 | "서버에 연결할 수 없습니다. 네트워크를 확인해주세요." |
    | 연결 실패 (Socket) | - | 폼 하단 오류 배너 | "세션이 생성되었지만 서버 연결에 실패했습니다. 다시 시도해주세요." |

### 2.3 우측 폼 — SESSION-01:ATTEND

**전체 공통:**
- 폼 타이틀: "NeoCAST Session" (중앙 정렬)
- 세션 코드 텍스트 필드에 코드 입력 (필수)
  - 플레이스홀더: "6자리 코드 입력"
  - 허용 문자: 영문 대문자 + 숫자 (입력 즉시 필터, 소문자 자동 대문자 변환)
  - **유효성 검증 조건 (클라이언트)**:
    1. 빈값: "세션 코드를 입력해주세요" — 코드 필드 하단 인라인
    2. 6자 미달: "6자리 코드를 입력해주세요" — 코드 필드 하단 인라인
  - **서버 오류 (코드 관련)**:
    - 코드 없음 (404): "존재하지 않는 세션입니다. 코드를 다시 확인해주세요." — 코드 필드 하단 인라인
    - 세션 종료 (410): "이미 종료된 세션입니다." — 코드 필드 하단 인라인
    - 이미 참여 중 (409): "이미 참여 중인 세션입니다." — 폼 하단 오류 배너
- 세션 비밀번호 텍스트 필드에 비밀번호 입력 (선택)
  - 플레이스홀더: "6자리 비밀번호"
  - 부연 텍스트: "호스트가 비밀번호를 설정한 경우 입력하세요."
  - 허용 문자: 영문 대소문자(A–Z, a–z) + 숫자(0–9)만 허용 (입력 즉시 필터)
  - **유효성 검증 조건 (클라이언트)**:
    1. 입력한 경우 정확히 6자 미달: "비밀번호는 6자리로 입력해주세요" — 비밀번호 필드 하단 인라인
  - **서버 오류 (비밀번호 관련)**:
    - 비밀번호 오류 (401): "비밀번호가 올바르지 않습니다." — 비밀번호 필드 하단 인라인
  - 최대 입력: 6자 초과 입력 불가 (입력 차단)
  - 빈값 허용: 비밀번호 없는 세션은 비워두고 참여
- [참여하기] 버튼 클릭하여 세션 참여 및 입장
  - 성공: 세션 입장
  - 조건: 항상 활성화 (클릭 시 유효성 검증 실행)
  - **서버 오류 처리 (공통)**:

    | 오류 상황 | HTTP | 표시 방식 | 메시지 |
    |----------|------|----------|--------|
    | 코드 없음 | 404 | 코드 필드 하단 인라인 | "존재하지 않는 세션입니다. 코드를 다시 확인해주세요." |
    | 세션 종료 | 410 | 코드 필드 하단 인라인 | "이미 종료된 세션입니다." |
    | 비밀번호 오류 | 401 | 비밀번호 필드 하단 인라인 | "비밀번호가 올바르지 않습니다." |
    | 게스트 참여 불가 | 403 | 폼 하단 오류 배너 | "이 세션은 게스트 참여가 허용되지 않습니다." |
    | 정원 초과 | 403 | 폼 하단 오류 배너 | "세션 정원이 가득 찼습니다." |
    | 이미 참여 중 | 409 | 폼 하단 오류 배너 | "이미 참여 중인 세션입니다." |
    | 인증 만료 | 401* | 오류 배너 + 자동 로그인 이동 | "로그인이 만료되었습니다. 다시 로그인해주세요." |
    | 서버 오류 | 500 | 폼 하단 오류 배너 | "서버 오류가 발생했습니다. 잠시 후 다시 시도해주세요." |
    | 네트워크 오류 | - | 폼 하단 오류 배너 | "서버에 연결할 수 없습니다. 네트워크를 확인해주세요." |

    > *401은 응답 body의 `code` 필드로 `INVALID_PASSWORD` vs `UNAUTHORIZED` 구분

## 3. 상태별 변화

### SESSION-01:CREATE

- **상태 설명**: [새 세션 생성] 선택 상태. 세션명 입력 및 설정 후 생성하는 폼
- **전환 트리거**: 화면 최초 진입 시 기본 상태 / 좌측 메뉴 [새 세션 생성] 클릭

#### 우측 폼

**전체 공통:**
- 세션명 필드 포커스 상태로 진입
- [생성하기] 버튼: 항상 활성화 (클릭 시 유효성 검증 실행)
- 세션명 글자 수: 입력창 우하단에 `N/30` 실시간 표시, 30자 도달 시 빨간색으로 전환

### SESSION-01:ATTEND

- **상태 설명**: [참여하기] 선택 상태. 세션 코드와 비밀번호(선택)를 입력하는 폼
- **전환 트리거**: 좌측 메뉴 [참여하기] 클릭

#### 우측 폼

**전체 공통:**
- 세션 코드 필드 포커스 상태로 전환
- [참여하기] 버튼: 세션 코드 미입력 시 비활성화, 입력 완료 시 활성화
