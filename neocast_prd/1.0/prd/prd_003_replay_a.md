## 1. 화면 개요 (Overview)

- **화면 ID**: `REPLAY-01`
- **화면명**: 필기 상세 (a안)
- **화면 경로**: 미정
- **Figma Node ID**: 미정
- **대상 사용자**: 로그인된 사용자 (교사)
- **비즈니스 목적**: 아카이브 상세에서 특정 참가자를 선택했을 때, 해당 참가자의 세션 내 필기 기록을 페이지별로 확인하고 리플레이할 수 있도록 한다.

### 주요 사용자 흐름 (Happy Path)

1. 아카이브 상세(`ARCHIVE-01`)에서 참가자 필기 카드를 클릭하여 진입한다.
2. 헤더에 `{이름}의 필기 상세`가 표시된다.
3. 좌측 전체 페이지 그리드에서 페이지 카드를 선택하면 우측 상세 영역에 해당 페이지 필기 이미지와 리플레이 플레이어가 표시된다.
4. 리플레이 플레이어에서 재생/정지, 배속, 앞뒤 이동 등을 조작한다.

## 2. 화면 구성 (Elements & Functions)

### 2.1 GNB

**전체 공통:**
- NeoCAST 로고 클릭하여 홈으로 이동
  - 조건: 항상 표시
- 언어 선택 드롭다운 클릭하여 UI 언어 변경
  - 성공: 선택한 언어로 UI 변경
- 사용자명 드롭다운 클릭하여 계정 메뉴 열기
  - 조건: 항상 표시

### 2.2 헤더

*표시 전용, 사용자 액션 없음.*

- 헤더 타이틀: `{이름}의 필기 상세`
  - 이름이 길어 헤더 영역을 초과할 경우 말줄임(...) 처리

### 2.3 전체 페이지 그리드 (좌측)

**전체 공통:**
- 페이지 카드 클릭하여 해당 페이지 선택
  - 성공: 우측 페이지 상세 영역에 선택한 페이지 필기 이미지 및 플레이어 표시
  - 표시 항목: 페이지 썸네일, 페이지 번호(NP)
  - 첨삭이 있는 페이지: 카드 상단에 ✓ 배지 표시
  - 기본 선택: 1페이지
- [이전 그룹] 버튼 클릭하여 이전 페이지 그룹으로 이동
  - 조건: 이전 페이지 그룹이 있을 경우에만 활성화
- [다음 그룹] 버튼 클릭하여 다음 페이지 그룹으로 이동
  - 조건: 다음 페이지 그룹이 있을 경우에만 활성화

### 2.4 페이지 상세 (우측)

**전체 공통:**
- 선택한 페이지의 필기 이미지 표시
- 리플레이 플레이어:
  - 재생 바(Seek Bar): 드래그하여 원하는 시점으로 이동
    - 성공: 해당 시점의 필기 상태로 이동
  - [재생/일시정지] 버튼 클릭하여 필기 리플레이 재생/정지
  - [1x] 배속 버튼 클릭하여 재생 속도 변경
    - 조건: 배속 옵션 별도 정의 필요 *(확인 필요)*
  - [-10초] 버튼 클릭하여 10초 뒤로 이동
  - [+10초] 버튼 클릭하여 10초 앞으로 이동
  - 현재 재생 시간 / 전체 길이 표시 (예: 00:00 / 00:32)
