## 1. 화면 개요 (Overview)

- **화면 ID**: `REPLAY-02`
- **화면명**: 필기 상세 (b안)
- **화면 경로**: 미정
- **Figma Node ID**: 미정
- **대상 사용자**: 로그인된 사용자 (교사)
- **비즈니스 목적**: 아카이브 상세에서 특정 참가자를 선택했을 때, 해당 참가자의 세션 내 필기 요약 정보와 페이지별 참여 현황을 확인하고 필기를 리플레이할 수 있도록 한다.

### 주요 사용자 흐름 (Happy Path)

1. 아카이브 상세(`ARCHIVE-01`)에서 참가자 필기 카드를 클릭하여 진입한다.
2. 헤더에 `{이름}의 필기 상세`가 표시된다.
3. 요약 카드(활동 시간 / 참여 페이지 / 받은 첨삭 수)를 확인한다.
4. 필기 페이지 그리드에서 페이지 카드를 클릭하면 필기 재생 모달(`REPLAY-02:MODAL`)이 열린다.
5. 피드백 다시보기 영역에서 첨삭이 있는 페이지 태그를 클릭하면 해당 그룹으로 이동한다.
6. 하단 페이지 참여 요약 테이블에서 페이지별 필기 시간 및 첨삭 여부를 확인한다.

## 2. 화면 구성 (Elements & Functions)

### 2.1 GNB

**전체 공통:**
- NeoCAST 로고 클릭하여 홈으로 이동
  - 조건: 항상 표시
- 언어 선택 드롭다운 클릭하여 UI 언어 변경
  - 성공: 선택한 언어로 UI 변경
- 사용자명 드롭다운 클릭하여 계정 메뉴 열기
  - 조건: 항상 표시

### 2.2 헤더

*표시 전용, 사용자 액션 없음.*

- 헤더 타이틀: `{이름}의 필기 상세`
  - 이름이 길어 헤더 영역을 초과할 경우 말줄임(...) 처리

### 2.3 요약 카드

*표시 전용 — 3개 카드 가로 배치.*

| 카드 | 표시 값 예시 | 비고 |
| :--- | :---------- | :--- |
| 활동 시간 | 15분 | 사용자가 필기한 총 사용 시간. 포맷 규칙: `duration < 60분` → `mm분`, `duration ≥ 60분` → `Xh Ym` |
| 참여 페이지 | 3 / 5 | 세션 전체 페이지 수 중 해당 게스트가 실제로 필기/전환한 페이지 수. 형식: `참여한 페이지 수 / 전체 페이지 수` |
| 받은 첨삭 수 | 2회 | 다른 참가자가 "스마트펜 입력"으로 내 페이지에 필기한 경우의 수 *(확인 필요)* |

### 2.4 필기 페이지 그리드

**전체 공통:**
- 페이지 카드 — 최대 4페이지씩 기본 노출, 그리드 형태 표시
  - 표시 항목: 페이지 썸네일, 페이지 번호(NP)
  - 기본 선택: 1페이지
- [이전 그룹] 버튼 클릭하여 이전 페이지 그룹으로 이동
  - 조건: 이전 페이지 그룹이 있을 경우에만 활성화
- [다음 그룹] 버튼 클릭하여 다음 페이지 그룹으로 이동
  - 조건: 다음 페이지 그룹이 있을 경우에만 활성화
- 페이지 카드 클릭 시 필기 재생 모달(`REPLAY-02:MODAL`) 열림
  - 성공: 해당 페이지의 필기 재생 모달 노출

### 2.5 피드백 다시보기

**전체 공통:**
- 세션 중 다른 참가자가 "스마트펜 입력" 기능으로 내 페이지에 필기한 경우에만 영역 노출
  - 없으면 해당 영역 숨김
  - 첨삭이 있는 페이지 번호 태그 표시 (예: 2P, 4P)
- 페이지 번호 태그 클릭 시 해당 페이지가 속한 그룹으로 이동
  - 성공: 필기 페이지 그리드가 해당 페이지 그룹으로 이동하며 해당 페이지 상단 영역 포커스

### 2.6 페이지 참여 요약 테이블

*표시 전용.*

| 열 | 내용 | 비고 |
| :--- | :--- | :--- |
| 페이지 | NP | 현재 선택된 페이지에 "현재" 표시 |
| 필기 시간 | N분 N초 | 해당 페이지에서 필기에 소요한 시간 |
| 첨삭 | ✓ / — | 첨삭 받은 페이지는 ✓, 없으면 — |

- 실시간 기록: 선택한 페이지에 해당하는 행 하이라이트 표시

## 3. 상태별 변화

### REPLAY-02:DEFAULT

- **상태 설명**: 화면 진입 시 기본 상태. 1페이지가 선택된 상태로 진입
- **전환 트리거**: 아카이브 상세(`ARCHIVE-01`) 참가자 카드 클릭 → 화면 진입

#### 필기 페이지 그리드

**전체 공통:**
- 1페이지 선택 상태로 노출
- 페이지 참여 요약 테이블 1P 행 하이라이트

### REPLAY-02:MODAL

- **상태 설명**: 필기 페이지 카드 클릭 시 열리는 필기 재생 모달
- **전환 트리거**: 필기 페이지 카드 클릭 → 모달 열림

#### 필기 재생 모달

**전체 공통:**
- 모달 타이틀: `필기 재생`
- 필기 이미지 영역: 선택한 페이지의 필기 상세 화면 노출
- 재생 컨트롤러:
  - 재생 바(Seek Bar): 드래그하여 원하는 시점으로 이동
    - 성공: 해당 시점의 필기 상태로 이동
  - [재생/일시정지] 버튼 클릭하여 필기 리플레이 재생/정지
  - [1x] 배속 버튼 클릭하여 재생 속도 변경
    - 조건: 배속 옵션 별도 정의 필요 *(확인 필요)*
  - [-10초] 버튼 클릭하여 10초 뒤로 이동
  - [+10초] 버튼 클릭하여 10초 앞으로 이동
  - 현재 재생 시간 / 전체 길이 표시 (예: 00:00 / 00:32)
- [X] 버튼 클릭하여 모달 닫기
  - 성공: 모달 닫힘, 이전 화면 유지
