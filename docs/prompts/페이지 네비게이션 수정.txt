❯ /login 페이지에서 로그인을 하고나서 / 의 랜딩페이지로 돌아가자. 현재는 로그인을 해면 바로 /lobby로 들어간다. 로그인이 된 상태에서는 / 의 랜딩 페이지에서 "시작하기" 버튼을 누르면 /lobby 로
  가도록 한다. 로그인이 안된 상태에서는 "시작하기"를 누르면 /login 페이지로 이동한다. (물론 거기서 로그인 하고 나면 / 의 랜딩 페이지로 돌아온다) 그리고 로그인 된 상태라면 우측 상단의 "로그인"
  버튼은 사라진다. 로그인 상태에서 로그아웃을 하면 /login으로 돌아가게 되어 있는데, 이것도 / 의  랜딩 페이지로 가도록 해라.
