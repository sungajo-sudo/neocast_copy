## 주요 변경사항

### 새로운 기능

#### Backend API (Server/src/routes/admin.ts)
기존 API 하위호환성 유지하며 새 엔드포인트 추가:

- `GET /admin/stats/users` - 이용자 통계 (등록자 수, 로그인 횟수, 평균 세션 시간)
- `GET /admin/stats/ncode` - NCode 발행 통계 (총 페이지, 교재 수, 고객 수)
- `GET /admin/stats/ncode/ranking` - 교재 등록 순위 (20명씩 페이징)
- `GET /admin/stats/chat` - 세션 채팅 통계 (메시지 수, 첨부파일 용량)
- `GET /admin/stats/messenger` - 메신저/DM 통계 (메시지, 스레드, 친구관계)
- `GET /admin/stats/storage-detailed` - 스토리지 상세 통계
- `GET /admin/papers` - PDF 목록 (페이징)
- `GET /admin/papers/:id` - PDF 상세 정보
- `GET /admin/papers/:id/preview` - PDF 미리보기 URL (서명된 GCS URL)

모든 통계 API는 period 파라미터 지원:
- `cumulative` (누적)
- `daily` (일간)
- `weekly` (주간)
- `monthly` (월간)
- `yearly` (연간)

#### Frontend (Server/admin-ui)

- **Layout.tsx**: 확장 가능한 네비게이션 메뉴 (대시보드 하위 메뉴 지원)
- **api.ts**: 새 API 클라이언트 함수 및 TypeScript 타입 정의
- **UserStatsPage.tsx**: 이용자 통계 페이지
- **NcodeStatsPage.tsx**: NCode 통계 + 랭킹 테이블
- **ChatStatsPage.tsx**: 채팅/메신저 통계
- **StoragePage.tsx**: 스토리지 + PDF 목록/미리보기
